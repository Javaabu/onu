`SensitiveInput` takes `masked` (default `true`; `false` shows the value as is, with no reveal button and the page direction unless `dir` is passed) and `mono` (default `true`). `CopyInput` remains as a preset (`masked={false}`, `mono` off by default); its docs and demo are now part of SensitiveInput. `CopyInput`'s input now also has `autocomplete="off"` and `spellcheck="false"`.
