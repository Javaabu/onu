`NumberInput` takes a unit and a stepper. `UnitInput` is removed: use `<NumberInput unit="kg" />` or `<NumberInput units={[{ value: "m", label: "m" }, { value: "km", label: "km" }]} defaultUnit="km" unitName="distance_unit" />`; the unit props keep their names (`unit`, `units`, `unitValue`, `defaultUnit`, `onUnitChange`, `unitName`, `unitLabel`, `unitPosition`, `classNames.unit` / `classNames.unitTrigger`), so replacing the component name is enough, and `UnitOption` is now `NumberInputUnitOption`. `QuantityStepper` is removed: use `<NumberInput stepper value={qty} onValueChange={setQty} min={1} max={20} />`, with `size`, `repeatDelay`, `repeatInterval` and `classNames.decrement` / `classNames.increment` as before. With `stepper` the value is a `number` (never empty: `min` defaults to `0`, `defaultValue` to `min`, and clearing falls back to `min`); `quantityStepperVariants` is now `numberInputVariants`, and the buttons' `data-slot`s are `number-input-decrement` / `number-input-increment`. A unit and the stepper can be combined, and `startAddon` / `endAddon` sit beside the unit. The types are `NumberInputFieldProps` and `NumberInputStepperProps` (`NumberInputProps` is their union).
