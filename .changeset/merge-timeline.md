`Timeline` is also an activity feed. Entries take an `actor` (`{ name, avatar? }`): the avatar is the marker and the name starts the title. New props: `groupByDay` (Today / Yesterday / date headings, with `dayFormat`), `title` (an `h2` that names it), `emptyText`, and `hasMore` / `onLoadMore` / `loadingMore` for a "Load more" button. With any of these, or with no items, the root is a labelled `<section>` holding the lists. `timeFormat="relative"` now renders `RelativeDate` ("1 hour ago", exact time on hover and focus, kept up to date), `now` accepts a string or timestamp, `description` renders in a `<div>`, and `classNames` gains `group`, `heading`, `empty` and `loadMore`. `ActivityFeed`, `ActivityFeedProps`, `ActivityItem`, `ActivityGroup` and `groupActivityByDay` are removed: use `<Timeline groupByDay timeFormat="relative" title="Activity" items={items} hasMore={…} onLoadMore={…} />` with `TimelineItem` (an item's `action` is `title`, `timestamp` is `time`, `detail` is `description`), `TimelineGroup` and `groupTimelineByDay`, which keeps the items' order (pass them newest first). There is no default heading: pass `title` to get one. The `display.activity`, `display.today`, `display.yesterday`, `display.loadMore` and `display.noActivity` strings are replaced by `layout.today`, `layout.yesterday`, `layout.loadMore` and `layout.noActivity`.
