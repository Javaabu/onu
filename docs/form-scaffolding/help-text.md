title: HelpText
sidebar_position: 8
---

Supporting text under a control. [`FormField`](./form-field) renders it from the `help` prop and links it with `aria-describedby`.

```tsx
import { HelpText } from "@javaabu/onu"

;<HelpText id="name-help">As shown on your ID card.</HelpText>
```

Accepts every `<p>` prop.
