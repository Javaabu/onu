This package requires:

- [React](https://react.dev) 19
- [Tailwind CSS](https://tailwindcss.com) 4
- [React Hook Form](https://react-hook-form.com) 7 and [TanStack Query](https://tanstack.com/query) 5, which share React context with your app

Onu supports every browser Tailwind CSS 4 supports: Chrome and Edge 111+, Safari 16.4+, Firefox 128+, and their mobile versions.

Some entry points need extra packages, installed only when you use them. [Peer dependencies per entry](./installation-and-setup#peer-dependencies-per-entry) lists them.
