# @javaabu/onu

## 0.1.0

### Minor Changes

- [`66fea37`](https://github.com/Javaabu/onu/commit/66fea379f8b16331f1e19508e40165095dffab83) Thanks [@claude](https://github.com/claude)! - Setting `--onu-primary` now re-brands the whole UI, not just buttons. The neutral tokens (`accent`, `secondary`, `muted`, `border`, `input` and the sidebar ones) are tinted with a little of the primary colour, and brand-coloured states use it: the active sidebar item (with a bar on sub-items), tab underlines, selected table rows, the current pagination page, calendar ranges and today, nav pills and stacked tabs, outline and ghost button hovers, pressed toggles, command items and text selection. Dark-mode `primary-subtle` is stronger so it shows on cards, and scoped `data-onu-theme` sections inside dark mode now get the lifted dark primary. Turn the tint down or off with `--onu-tint` (e.g. `0%`) or `data-onu-tint="none"`; setting a token such as `--onu-accent` still replaces it, and the untinted values are available as `--onu-neutral-*`. The light `muted-foreground` is slightly darker (`oklch(0.5 0 0)`) to keep AA contrast on tinted surfaces.

- [`45ec6ed`](https://github.com/Javaabu/onu/commit/45ec6ed99ad5aa037f436a202b18da8bfd7dca8c) Thanks [@claude](https://github.com/claude)! - Charts: add `ChartAnimationProvider` (and export `useChartAnimation`) to turn animation off for every Onu chart in an area, e.g. for print, kiosks or screenshot tests. Tooltips now also stop animating under `prefers-reduced-motion`, so every Onu chart passes `isAnimationActive={false}` to all its Recharts elements when reduced motion is preferred. The visual regression spec emulates reduced motion and loads fonts before charts render, so chart screenshots are stable.

- [`e7de10b`](https://github.com/Javaabu/onu/commit/e7de10b5cb43507a12b95d9e1d876f419a68ca15) Thanks [@claude](https://github.com/claude)! - Charts: gradient fills, on by default. Areas (`LineChart` and `TimeSeriesChart` areas, stacked areas, `Sparkline`, `StatTile` sparklines) fade from the series colour to almost clear at the baseline, bars (`BarChart` vertical, horizontal and stacked, `TimeSeriesChart` bars, `PeriodComparisonChart` bars) run from a lighter base to the full colour (mirrored for negative values and for horizontal bars in RTL), and the `PeriodComparisonChart` line variant gets a soft wash under the current period. Gradients use the series colour, so they follow the theme and `--onu-primary`, have ids unique per chart instance, and fall back to solid in forced-colours mode. Turn them off with `gradient={false}` on a chart (`sparklineGradient` on `StatTile`) or for an area with the new `ChartStyleProvider gradient={false}`; `useChartGradient` is exported for custom charts. Pie and donut slices stay solid. Tooltip and legend swatches stay solid when a series is filled with a gradient.

- [`672865d`](https://github.com/Javaabu/onu/commit/672865d227e5f7596c7f333eea3134f31ed444ad) Thanks [@claude](https://github.com/claude)! - Charts (`@javaabu/onu/charts`): BarChart, LineChart, PieChart, TimeSeriesChart, PeriodComparisonChart, Sparkline, StatTile/StatTiles, DeltaIndicator and MapChart, plus the shadcn chart primitives and locale-aware formatters (`formatMVR`, `useChartFormat`).

- [`fd269fe`](https://github.com/Javaabu/onu/commit/fd269fe1ca3eb73ed9ec0aba1231324b0b364462) Thanks [@claude](https://github.com/claude)! - New `@javaabu/onu/export` entry: `exportRows({ format, rows, columns, filename, title, scope })` and `useExportRows()` build CSV, Excel or PDF files in the browser, so `ExportMenu` / `ListingPage` can export without a server in one line (`onExport={(format) => exportRows({ format, rows, columns })}`). Columns take a header, an accessor (key, dotted path or function) and an optional type (`text`, `number`, `currency`, `date`, `datetime`, `boolean`) and formatter. CSV is UTF-8 with a BOM, RFC 4180 quoted and guarded against formula injection. Excel uses the optional `write-excel-file` peer (loaded on first use), keeps numbers numeric and dates as dates, and writes right-to-left sheets for Dhivehi. PDF opens the print dialog with a paginated, escaped table document (title, scope, generated date, repeated header row, page numbers, `dir`/`lang`, Onu fonts), so Thaana renders correctly. Per-format helpers (`toCsv`, `buildExcelSheet`, `toExcelBlob`, `buildPrintDocument`, `printHtml`, …) are exported too.

- [`7dd220a`](https://github.com/Javaabu/onu/commit/7dd220a164b6799ca2633b3ec326db61ac412fe5) Thanks [@claude](https://github.com/claude)! - Display and feedback components: DescriptionList, StatusBadge, Tag, UserAvatar, UserAvatarGroup, KeyboardKey, Callout, Notice, AnnouncementBar, CookieConsent, Toaster/toast, ConditionalLink, ConditionalDisplay, PublishBox, LastEditedBy, RelativeDate, Countdown, ActivityFeed, CommentThread, Notes, IconText, ShareButtons, PrintButton/BackButton, MiniCalendar, ContentCard and error pages (403, 404, 500, 503). - [`1d39453`](https://github.com/Javaabu/onu/commit/1d39453d51837bb7eed36d494805003130c05dc2) Thanks [@claude](https://github.com/claude)! - `DropzoneUploader`: controlled `value` / `onValueChange` and `defaultValue` for its file list, so an edit page can show files already saved on the record (`{ id, name, size?, type?, url?, thumbnailUrl? }`), let the user remove them, and submit the kept ids as hidden inputs. With an uploader, finished uploads are added to the value (`{ id, name, size, type, file, response }`); without one, picked `File`s are. Existing files count toward `maxFiles`; removing a file moves focus back to the Browse button and is announced. New types `DropzoneFile` and `UploadedFile`. Without the new props the uploader behaves as before, except that with `multiple={false}` and an uploader, a finished upload now replaces the previous one instead of listing both.
